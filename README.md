# “双碳”目标背景下行业规制暴露与上市公司碳信息披露 —— 实证复现仓库

作者：蔡璋睿（宁波大学 经济学 2024 级）｜论文学生一作（在投）｜2026.11

## 研究问题

行业规制暴露是否提高上市公司碳减排信息披露概率？暴露强度与披露概率之间是否存在可识别的“剂量—反应”关系？

## 数据规模

- 基础面板：5,514 家公司、28,256 条公司—年度观测
- R2 规则后：4,235 家公司、24,383 条观测
- 主回归样本：15,211 条
- 结果变量：数据库记录的碳减排信息披露虚拟变量

## 方法

- 暴露：0–4 行业规制暴露序数指标
- 主模型：企业与年份双向固定效应 LPM（系数直接解释为披露概率的百分点变化）
- 识别稳健性：七种匹配（1:1 近邻 / 无卡尺 / 1:4 近邻 / 半径 / 核 / 马氏 / IPW-ATT）、300 次随机化置换检验、连续与分级剂量反应、省×年份固定效应、伪时点检验、动态剂量

## 主要结果

- 暴露得分每增加 1 单位，披露概率提高约 **1.29 个百分点**（Post22 口径约 1.45 个百分点）
- 剂量—反应呈正向梯度，七种匹配方向一致
- **结论定位：关联证据，不声称确定政策因果效应**

## 结果与局限（诚实披露）

- 行业层聚类与野生聚类自助下显著性减弱（企业 t≈2.26 / 省份 t≈2.53 / 行业 t≈1.81，阈值 1.96）
- 排放数据为按省×部门清单与样本营收份额构造的**代理变量**，非企业实测排放
- 自报减排量结果不稳健，未纳入主结论
- 政策前实际可用窗口仅 2019 年，事前平行趋势检验受限
- 披露为二元口径，无法识别披露质量差异

## 目录结构与流水线

```
scripts/
  step1b_clean_2024.py      2024 年增量数据清洗
  step2_carbon_build.py     单位统一、R1 纠错、公司—年度去重、面板合并、TWFE 快速回归
  step3_carbon_strengthen.py 持续披露子样本、熵平衡/PSM、两部分模型、300 次随机化安慰剂、动态效应
  step4_matching_suite.py   七种匹配：近邻/无卡尺/1:4/半径/核/马氏/IPW-ATT
  step5_dose_response.py    连续剂量、分级剂量、替代评分
  step6_dose_identification.py 伪时点、随机强度、动态剂量、省×年份 FE、高碳子样本
  step7_audit.py            Disclose_any 并集、asinh 负值口径、聚类层级、纠错阈值敏感性
results/                    各步结构化结果（JSON 留档，可直接核对论文数字）
figures/dose_dynamics.png   剂量—反应动态图（step5/step6 产出）
```

按 step1b → step2 → … → step7 顺序执行；每步读上一步的中间产物、写出 JSON 结果，随机过程均固定种子。

## 复现方式

1. 环境：Python 3.10+，依赖见 `requirements.txt`（pandas、numpy、pyreadstat）。
2. 数据：原始输入（上市公司碳减排数据库 CNDD-0272、CEADs 排放清单、财务面板）为授权获取的数据，**未包含在本仓库中**，详见“数据可得性”。
3. 将各脚本中的 `WS` 常量改为存放原始数据的目录路径后，按序运行：

```bash
pip install -r requirements.txt
python scripts/step2_carbon_build.py
python scripts/step3_carbon_strengthen.py
python scripts/step4_matching_suite.py
python scripts/step5_dose_response.py
python scripts/step6_dose_identification.py
python scripts/step7_audit.py
```

4. 核对：`results/` 中的 JSON 与论文实证结果报告一一对应。

## 数据可得性

原始数据（CNDD-0272 上市公司碳减排情况、CEADs 碳排放清单、上市公司财务面板）均来自授权数据库，受许可协议限制不能公开再分发。本仓库提供完整的处理代码、结构化结果与图表，供方法审查与复现核对；如需原始数据，请通过相应数据商或 CEADs 官方渠道获取。
